# フィルムカメラ

撮影中のプレビューの時点で、フィルム風・フラッシュ風・岩井俊二風に見える iPhone 用カメラアプリです。

- **フィルム**：低いコントラスト・クリーム色の白・緑っぽい影・ふんわりしたにじみ・粒子
- **フラッシュ**：2000年代のコンデジの直射フラッシュ風（白飛び・黒つぶれ・濃い色）
- **暖フラッシュ**：フラッシュの色を黄〜橙に寄せたもの
- **岩井俊二風**：明るめ・淡い水色・低い彩度・やわらかな光
- **多重露光**：2 回シャッターを切ると 1 枚に重なる（撮影中の画面にも 1 枚目が透けて見える）
- **クロス**：暖色と寒色がぶつかる、濃く硬い色（クロスプロセス風）
- 音量ボタン（iPhone 16 はカメラコントロールも）でシャッター
- 日付の写し込み（オレンジの文字）、インカメラ切り替え（ダブルタップでも可）、左右スワイプでモード切り替え

ビルドと TestFlight 配信は GitHub Actions で行います（`CLAUDE.md` 参照）。
